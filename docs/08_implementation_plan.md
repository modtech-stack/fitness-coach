# AI Fitness Trainer
# Implementation Plan

**Статус:** утверждён 2026-07-27.

## Цель

Создать минимальный рабочий MVP для двух пилотных пользователей, который замыкает цикл:

`профиль → программа → review → выполнение → check-in → решение Training Engine → обратная связь`

## Архитектурное направление

- модульный монолит на Next.js и TypeScript;
- Supabase для PostgreSQL, Auth и Row Level Security;
- OpenAI API только для Program Builder и некритичных объяснений;
- детерминированный Training Engine без LLM в контуре принятия критических решений;
- ручной ввод данных в первом MVP;
- плановая и фактическая тренировки хранятся отдельно;
- программы и решения движка версионируются и доступны для аудита.

Конкретные технические решения могут уточняться только через [DECISIONS.md](DECISIONS.md).

## Этап 0. Консолидация источника истины

Цель: собрать весь актуальный контекст в каталогах ветки `main`, исправить ссылки, удалить вводящие в заблуждение пустые спецификации и заменить реальные профили синтетическими примерами.

Критерий готовности: новый разработчик получает полный актуальный контекст, клонировав только `main`.

## Этап 1. Доменные контракты и база

- определить статусы программ, тренировок и решений;
- создать схему PostgreSQL;
- настроить Supabase Auth и RLS;
- реализовать роли `user` и `reviewer`;
- подготовить изолированные пилотные аккаунты.

## Этап 2. Первый внутренний вертикальный срез

- onboarding;
- профиль и цель;
- ручной ежедневный check-in;
- заранее подготовленная утверждённая программа;
- экран сегодняшней тренировки;
- запись фактического результата.

На этом внутреннем milestone GPT Program Builder ещё не обязателен.

**Статус на 2026-08-03:** реализован как Training Workflow Foundation.
План хранится в нормализованной иерархии, факт — отдельно. Пользователь
явно добавляет подготовленную синтетическую программу, открывает
сегодняшнюю тренировку, записывает подходы, вес, RPE и комментарий,
после чего видит результат в истории. GPT Program Builder и Training
Engine в этот этап не входят.

### Stage 2.1 — улучшение тренировочного workflow

**Статус на 2026-08-03:** реализован поверх Training Workflow Foundation.

- авторизованный пользователь сразу попадает на Dashboard;
- Dashboard показывает один понятный следующий шаг;
- основная навигация показывает текущий раздел;
- название, дата начала и длительность активной программы редактируются вручную;
- содержание запланированной тренировки и рабочие веса редактируются только до её выполнения;
- выполненная тренировка и фактические подходы остаются неизменяемыми;
- форма продуктовой обратной связи сохраняет пользователя, страницу, сообщение и время;
- интерфейс выполнения тренировки адаптируется для desktop, tablet и mobile.

Stage 2.1 не добавляет генерацию программы, автоматическую перестройку недель,
Training Engine, логику разминки или сложную аналитику.

### Stage 2.2A — UX Foundation + bug fixes

**Статус на 2026-08-11:** реализуется поверх Stage 2.1.

- цель и ограничение формулируются пользователем свободным текстом без обязательного
  выбора внутреннего типа;
- подсказки дают конкретные примеры результата, боли/травмы, времени, оборудования
  и бытовых условий;
- несколько ограничений сохраняются отдельными записями;
- feedback и редактирование длительности зависят от функций миграции Stage 2.1;
  hosted development schema должна получать все versioned migrations до UI-проверки;
- общий UX review охватывает Dashboard, цели, ограничения, программу, сегодня,
  историю и мобильную версию.

Stage 2.2A не добавляет импорт Excel или Google Sheets, Progression Engine, GPT
Program Builder, Training Engine и wearable-интеграции.

## Этап 3. Training Engine v1

Реализовать и протестировать:

- медицинские красные флаги и маршрутизацию;
- болезнь и возвращение после болезни;
- боль и ухудшение техники;
- сон, самочувствие и усталость;
- недавнюю нагрузку, шаги и поездки;
- запрет компенсации пропущенных тренировок;
- силовую и аэробную прогрессию;
- объяснение каждого решения.

Обязательные тесты перечислены в разделе 6.26 [Training Engine Principles](../knowledge/training/training_engine_principles_v0.9.md).

## Этап 4. GPT Program Builder и review

- versioned prompt;
- строгая JSON-схема программы;
- детерминированные проверки результата;
- генерация только статуса Draft;
- review и комментарии;
- явное утверждение и активация версии;
- audit trail генерации.

## Этап 5. Feedback loop и прогресс

- post-workout feedback;
- сравнение плановой и фактической нагрузки;
- базовая динамика показателей;
- предложение корректировки;
- новая версия программы после подтверждения.

## Этап 6. Пилот

- минимум восемь недель использования;
- анализ ложных ограничений и пропущенных рисков;
- оценка качества программ и причин невыполнения;
- внешнее review safety-правил перед расширением аудитории.

## Не входит в первый MVP

- мобильное приложение;
- микросервисы;
- социальные функции;
- vector database и RAG;
- автоматические wearable-интеграции;
- ML readiness score;
- прогноз травм;
- медицинская диагностика;
- полноценный редактор правил;
- коммерческая инфраструктура.
