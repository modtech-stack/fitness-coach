# AI Fitness Trainer
# MVP Specification v1.0


# 1. Цель MVP

Создать первую рабочую версию AI Fitness Trainer для двух пользователей:

- Борис;
- Алёна.

MVP должен проверить гипотезу:

"Может ли AI помочь человеку создать, выполнить и адаптировать персональную тренировочную программу лучше, чем обычная таблица и чат?"


---

# 2. Пользовательские роли


## User

Пользователь:

- создаёт профиль;
- задаёт цели;
- указывает ограничения;
- получает программу;
- выполняет тренировки;
- получает рекомендации.


## Program Reviewer

В MVP:

Борис.

Функции:

- проверяет программу;
- обсуждает её с GPT;
- подтверждает или изменяет.


В будущем:

- тренер.


---

# 3. Основные пользовательские сценарии


## Сценарий 1.
Создание профиля


Пользователь вводит:

- возраст;
- пол;
- рост;
- вес;
- опыт тренировок;
- цель;
- доступное время;
- оборудование;
- ограничения;
- предпочтения.


Результат:

Создан профиль пользователя.


---

## Сценарий 2.
Создание тренировочной программы


GPT получает:

- профиль;
- цель;
- ограничения.


Создаёт:


### Макроцикл

Например:

12 недель.


### Мезоциклы

Например:

Фаза 1:
адаптация

Фаза 2:
прогрессия

Фаза 3:
закрепление


### Микроциклы

Недельный план:

- дни тренировок;
- упражнения;
- объём;
- интенсивность;
- прогрессия.


Статус:

Draft.


---

## Сценарий 3.
Аудит программы


Reviewer проверяет:

- соответствие цели;
- объём;
- баланс мышечных групп;
- последовательность нагрузок;
- восстановление;
- реалистичность.


Результат:

Approved / Changes required.


---

## Сценарий 4.
Выполнение тренировки


Пользователь видит:

Сегодня:

- тип тренировки;
- упражнения;
- подходы;
- повторения;
- цель нагрузки.


После тренировки:

записывает:

- фактический вес;
- повторения;
- RPE;
- комментарии.


---

## Сценарий 5.
Ежедневная адаптация


Система анализирует:

- сон;
- самочувствие;
- боль;
- болезнь;
- ЧСС покоя;
- предыдущую нагрузку.


Training Engine выдаёт:

- выполнить план;
- снизить нагрузку;
- заменить тренировку;
- восстановиться.


---

# 4. Что входит в MVP


Обязательно:

## Пользователь

✓ профиль

✓ цели

✓ ограничения


## Program Builder

✓ генерация программы GPT

✓ макроцикл

✓ мезоциклы

✓ микроциклы


## Program Review

✓ статус программы

✓ комментарии

✓ утверждение


## Training Log

✓ плановая тренировка

✓ фактическая тренировка

✓ результаты


## Training Engine v1

✓ сон

✓ самочувствие

✓ болезнь

✓ боль

✓ корректировка нагрузки


---

# 5. Что НЕ входит в MVP


Не делаем:

- мобильное приложение;
- социальные функции;
- магазин программ;
- автоматическую замену тренера;
- сложный ML;
- прогноз травм;
- автоматическую генерацию из библиотеки блоков.


---

# 6. MVP архитектура


User

↓

Web App

↓

Database

↓

GPT Program Builder

↓

Training Engine

↓

AI Coach


---

# 7. Критерий успеха MVP


MVP успешен, если:

- Борис и Алёна используют приложение минимум 8 недель;
- создают программы;
- выполняют тренировки;
- получают полезные корректировки;
- находят ошибки в логике программ.
